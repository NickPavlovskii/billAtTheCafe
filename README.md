# Cafe Bill Splitter

Веб-приложение для честного разделения счёта в кафе между несколькими людьми.
Без споров, без калькулятора — просто выбери, кто что ел.

**Демо:** [Cafe Bill Splitter на Netlify](https://main--regal-smakager-265371.netlify.app/)

## Возможности

- **Добавление участников** — введи имена всех за столом, каждый получает уникальный цветной аватар
- **Позиции меню** — добавляй блюда с ценой и выбирай, кто их ел (одинарный выбор или «Все»)
- **Расчёт долей** — автоматически делит стоимость блюда поровну между выбранными участниками
- **Чаевые** — настраиваемый процент (0–100%), предустановки 0/5/10/15/20%
- **Кто кому должен** — минимальный набор переводов на основе фактических оплат
- **Экспорт** — сохранить PDF, отправить в Telegram или WhatsApp
- **Светлая / тёмная тема** — плавные переходы, сохраняется в `localStorage`
- **Mobile-first** — адаптивный дизайн, поддержка safe-area на iPhone, предотвращение zoom при фокусе
- **Ручной мобильный дизайн** — единые зоны нажатия (min 44px), отступы через CSS-переменные (`--mobile-tap-min`, `--mobile-padding-x`, `--mobile-gap`), на узких экранах карточка без скруглений и тени для полноэкранного вида
- **PWA** — можно установить на телефон или компьютер (домашний экран), работает офлайн после первой загрузки
- **Скопировать расчёт** — кнопка «Скопировать» на экране расчётов копирует текст «Кто кому переводит» в буфер, показывается подсказка «Скопировано в буфер»

## Предложения по улучшению функционала

Идеи для следующих версий:

| Идея | Описание |
|------|----------|
| **Валюта** | Выбор валюты (руб., ₽, $, €) в настройках и отображение везде. |
| **История расчётов** | Сохранять последний расчёт в `localStorage` и показывать «Продолжить с прошлого раза» на главном экране (опционально). |
| **Доля не поровну** | Для позиции указывать, например, «2 доли» одному и «1 доля» другому — деление стоимости не поровну (половинки, 2/3 и т.д.). |
| **Скидка по промо** | Поле «Скидка на чек» (сумма или %) и пересчёт итога и долей с учётом скидки. |
| **Подсветка «Моя доля»** | В настройках ввод «Моё имя» — на экране результата и в блоке «Кто кому переводит» выделять строки, где участвует этот человек. |
| **Голосовой ввод** | Добавление участника или позиции голосом (Web Speech API) для удобства за столом. |
| **Офлайн-подсказки** | В PWA при первом офлайн-заходе показывать короткий тултип: «Данные хранятся только на устройстве». |

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/NickPavlovskii/billAtTheCafe
cd billAtTheCafe

# Установить зависимости
npm install

# Режим разработки
npm run serve            # http://localhost:8080

# Сборка для продакшена
npm run build

# Запуск тестов
npx vitest

# Storybook
npm run storybook        # http://localhost:6006
```

> **PDF с кириллицей:** положите файл `Roboto-Regular.ttf` в папку `public/fonts/`.
> Без него PDF сохранится, но кириллица может отображаться некорректно.

## Как пользоваться

### Шаг 1 — Участники
1. Введите имя участника в поле ввода
2. Нажмите **«+»** или **Enter** для добавления
3. Добавьте минимум **2 участников**
4. Нажмите **«Далее»**

### Шаг 2 — Позиции
1. Введите название блюда
2. Укажите стоимость (в рублях)
3. Выберите **кто ел** это блюдо с помощью кнопок-чипов, или нажмите **«Все»**
4. Нажмите **«Добавить позицию»**
5. Добавьте минимум **2 позиции**, затем нажмите **«Результат»**

### Шаг 3 — Результат
1. Таблица показывает, сколько должен каждый участник (с учётом чаевых)
2. В колонку **«Заплатил»** введите фактически внесённую сумму для каждого
3. Нажмите **«Кто кому должен»** — появится список минимальных переводов
4. Экспортируйте: **PDF**, **Telegram** или **WhatsApp**

## Компоненты

### `App.vue`
Корневой компонент. Управляет:
- Навигацией между экранами через стек `screenHistory`
- Индикатором шагов (step-indicator) и прогресс-баром
- Глобальным состоянием: `people`, `positions`, `defaultTip`, `theme`
- Валидационными bottom-sheet модальными окнами

**Поток экранов:** `main-component` → `add-persons` → `add-positions` → `bill-result`
(плюс `settings` из любого экрана через шестерёнку)

### `AddPerson.vue`
- Ввод имён через **PrimeVue InputText**
- Анимированный список участников (`transition-group`) с цветными аватарами
- Пустое состояние с подсказкой

### `AddPositionForm.vue`
- Форма с **PrimeVue InputText** для названия и цены блюда
- Чипы-кнопки с аватарами для выбора участников
- Валидация через bottom-sheet с анимацией

### `BillResult.vue`
- Сводные карточки: сумма, чаевые, итого
- Таблица с полями ввода «Заплатил» для каждого участника
- **Алгоритм расчёта долгов:** жадный алгоритм, минимальное число переводов
- Экспорт в PDF и текстовый шаринг

### `BillSettings.vue`
- Stepper для выбора % чаевых с пресетами (btnn-стиль)
- Превью тем (светлая/тёмная) с mini-UI
- Сохранение в `localStorage` (`defaultTip`, `theme`)

### `BaseButton.vue` / `BackButton.vue`
Фирменная кнопка в «btnn»-стиле:
- Наружный слой: `var(--btn-outer)`
- Внутренняя вставка `::before`: `var(--btn-inner)`
- Угловые клипы `.i::before`/`.i::after` с акцентными бордерами `var(--btn-clip)`
- Hover: фон → акцентный цвет, клипы разлетаются с тенью
- Полностью адаптирована к светлой и тёмной теме

## Темизация

Все цвета определены через CSS-переменные в [`src/styles/theme.css`](src/styles/theme.css).

### Основные переменные

| Переменная | Описание |
|---|---|
| `--app-bg` | Фон страницы |
| `--card-bg` | Фон карточки приложения |
| `--text-primary` | Основной текст |
| `--text-secondary` | Вторичный текст |
| `--accent` | Акцентный синий |
| `--accent-soft` | Полупрозрачный акцент для подложек |
| `--surface` | Фон поверхностей (инпуты, мини-карточки) |
| `--surface-border` | Граница поверхностей |

### Переменные кнопок (btnn-стиль)

| Переменная | Светлая тема | Тёмная тема |
|---|---|---|
| `--btn-outer` | `#c4d4e8` | `#3a3d44` |
| `--btn-inner` | `#ddeaf8` | `#27282c` |
| `--btn-color` | `rgba(10,30,80,0.5)` | `rgba(255,255,255,0.616)` |
| `--btn-clip` | `#048bfa` | `#3a9eff` |

### Переключение темы

```js
// Программное переключение
document.body.className = 'light-theme' // или 'dark-theme'
localStorage.setItem('theme', 'dark')
```
